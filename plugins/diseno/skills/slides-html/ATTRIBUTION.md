# Atribución

Los siguientes archivos del motor provienen del proyecto
[frontend-slides](https://github.com/zarazhangrui/frontend-slides) de
zarazhangrui, licencia MIT, vendorizados el 2026-07-28 tras revisión manual
(sin scripts ejecutables de terceros):

- `viewport-base.css` — CSS obligatorio del stage fijo 16:9
- `html-template.md` — arquitectura HTML y características JS
- `animation-patterns.md` — referencia de patrones de animación
- `STYLE_PRESETS.md` — 12 presets visuales curados (modo personal)

El flujo de trabajo (SKILL.md), el brand pack `brands/ccd/` y las adaptaciones
al español son obra propia. Los logos de `brands/ccd/logos/` son propiedad del
CCD / EGTP / Tecnológico de Monterrey y se usan solo para materiales
institucionales del usuario.

NO se vendorizaron los scripts del proyecto original (`extract-pptx.py`,
`deploy.sh`, `export-pdf.sh`) ni el `bold-template-pack` (34 sistemas de
diseño). Si se desea el paquete completo de templates para el modo personal,
instalar el original con:

    /plugin marketplace add https://github.com/zarazhangrui/frontend-slides

o clonarlo manualmente y esta skill lo detectará en
`~/.claude/skills/frontend-slides/bold-template-pack/`.
