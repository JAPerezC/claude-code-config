# Política de Seguridad

## Versiones soportadas

Solo la rama `main` recibe parches de seguridad activamente.

| Versión | Soportada |
|---|---|
| latest (main) | sí |
| versiones anteriores | no |

## Reportar una vulnerabilidad

**No abras un issue público para reportar vulnerabilidades.**

Para reportar:

1. Usa GitHub Security Advisories: ve a la pestaña **Security** del repo → **Report a vulnerability**.
2. Alternativa: envía un correo a `61630997+JAPerezC@users.noreply.github.com` con:
   - Descripción del problema
   - Pasos para reproducir
   - Impacto estimado
   - Tu nombre y forma de contacto (opcional)

## Tiempos de respuesta

- **Acknowledgement**: dentro de las 72 horas.
- **Análisis inicial**: dentro de 7 días.
- **Fix o mitigación**: depende de severidad. Críticas en ≤14 días, altas en ≤30 días.

## Reconocimiento

Si lo reportas con responsabilidad, te incluyo en los release notes (con tu consentimiento) y en la sección de agradecimientos del repo.
